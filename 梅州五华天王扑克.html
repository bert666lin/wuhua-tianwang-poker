梅州五华天王扑克 小程序完整需求文档

文档版本：V1.1 ｜ 适用：微信小程序开发 ｜ 面向OpenClaw工程化开发

合规硬性约束（必须严格执行）
  1. 禁止任何现金充值、房卡付费、金币兑换、赌博相关功能，仅做纯娱乐积分，积分仅本局有效，不可提现、不可跨局累计交易。
  2. UI文案禁止出现“赌博、下注、赌资、充值赢钱”等违规词汇。
  3. 小程序类目建议选择：娱乐 → 休闲娱乐。

一、项目概述

五华天王是梅州五华地区经典升级类扑克游戏，核心特色为方块3 = 天王（全场最大牌），采用「1庄家 VS 多闲家同盟」的对抗模式，通过叫主、叫分抢庄、扣底、甩牌、抠底完成对局。

本项目支持多人数+多副牌可配置，核心逻辑统一复用，仅通过配置表切换参数，降低开发成本。

三、全局通用核心规则（所有模式完全一致）

3.1 常主与牌力排序

常主：永远为主牌，不受主花色影响。包含：方块3（天王）、大王、小王、全部7、全部2

牌力从大到小排序：

方块3(天王) ＞ 大王 ＞ 小王 ＞ 主7 ＞ 副7 ＞ 主2 ＞ 副2 ＞ A ＞ K ＞ Q ＞ J ＞ 10 ＞ 9 ＞ 8 ＞ 6 ＞ 5 ＞ 4 ＞ 普通3
  • 主7大于所有副7；主2大于所有副2。
  • 同级别的副7、副2之间，先出牌者更大。

3.2 分数牌

  • 5 = 5分，10 = 10分，K = 10分。
  • 每副牌总分50分，N副牌总分 = 50 × N。

3.3 支持牌型

  1. 单张：任意一张牌。
  2. 对子：两张点数、花色完全相同的牌。
  3. 三张：三张点数、花色完全相同的牌。
  4. 连对（拖拉机）：至少 2 组同花色、连续的对子，组数不限。如 33+44、33+44+55+66；允许 K-A-2-3 跨接。
  5. 连三张：至少 2 组同花色、连续的三张。如 444+555、444+555+666。
  6. 王组合：大王组 + 小王组且两组张数相同。如大王对+小王对、三大王+三小王。王组合能压同张数的连对和连三张。
  7. 甩牌：首家可甩出同花色的若干单张+若干对子，要求甩出的每一张/每一对都是该花色场上现存最大。
连对／连三张的硬约束
  • 主牌和副牌不能一起成组。7 和 2 是常主（主牌），所以副花色连对不能含 7 或 2，也不能跨过它们接续。 例：主是♠时，♦6♦6+♦7♦7 和 ♦6♦6+♦8♦8 都不成立；但主是♦时整手都是主牌，♦6♦6+♦7♦7 就成立。
  • 大小王没有花色，不能参与连对／连三张（要成组只能用「王组合」）。
  • 组合牌型按牌面点数比大小。主花色的 3 是天王，但在连对／连三张里只按点数 3 参与， 单出或出对子、三张时才是最大牌。
禁止牌型
  • 不支持顺子（五张及以上同花色连续单张不是合法牌型）。

3.4 跟牌规则

  1. 首家出任意花色，其他玩家有同花色必须跟同花色。
  2. 首家出对子，玩家有同花色对子必须跟对子；无对子则跟同花色单张。
  3. 无首家花色时：可垫其他副牌（无法赢本轮），或用主牌杀牌赢下本轮。
  4. 主牌可以杀任意副牌；不同副花色之间，首家花色为大，其余为垫牌。

3.5 甩牌校验规则

  1. 首家可以甩主牌；副牌是否可甩由房间开关控制（默认开启）。
  2. 甩出的所有单张、对子，必须是该花色当前场上剩余牌中的最大。
  3. 若任意玩家手中存在比甩出的某张/某对更大的牌 → 甩牌失败，强制玩家出该花色最小的一张牌，整套甩牌作废。

3.6 抠底规则

  1. 最后一轮出牌，获胜方若打出的是主牌，则触发抠底：底牌中所有分数全部归获胜阵营。
  2. 最后一轮获胜方打出的是副牌 → 不抠底，底牌分数直接作废。
  3. 庄家赢抠底：底牌分计入庄家得分；闲家赢抠底：底牌分计入闲家总得分。

四、完整游戏流程

所有模式流程一致：创建房间 → 人满开局 → 发牌+叫主 → 叫分定庄 → 庄家扣底 → 出牌对局 → 抠底结算 → 积分结算 → 下一局

4.1 发牌与叫主阶段

  1. 系统洗牌，逆时针发牌；发牌过程中同步开放叫主权限。
  2. 玩家手牌中有7，可亮出一张7定主花色，该7的花色即为本局主花色。
  3. 每人仅1次叫主机会，放弃后本局不可再叫主。
  4. 后续玩家可亮出其他花色7进行反主，覆盖当前主花色。
  5. 全程无人叫主：翻开底牌第6张，以该牌花色定主；翻出大小王则顺延下一张。

4.2 叫分与定庄家

  1. 逆时针轮流叫分，只能报5的倍数，不可高于上限、不可低于下限。
  2. 玩家可选择「叫更低分」或「放弃」；放弃后本局不可再参与叫分。
  3. 叫分最低者成为本局庄家。庄家目标：本局得分 ≥ 叫分；闲家目标：阻止庄家达到叫分。
  4. 全部玩家放弃叫分 → 流局
    • 不进行出牌环节；
    • 统计所有玩家「流动主」数量：流动主 = 天王 + 大小王 + 全部7 + 全部2；
    • 流动主数量最多的玩家为本局负方，扣除对应积分，直接开启下一局。

4.3 底牌与扣底

  1. 庄家获得全部底牌，手牌数量 = 发牌数 + 底牌数。
  2. 庄家必须选出对应数量的牌扣回底牌（扣底），手牌回到初始发牌数。
  3. 扣底数量不符时，禁止确认扣底。
  4. 扣底牌对其他玩家不可见，仅结算时翻开。

4.4 出牌对局

  1. 庄家首轮先出牌；后续每轮由上一轮最大牌玩家先出牌。
  2. 逆时针轮流出牌，遵循跟牌规则。
  3. 每轮结束后，获胜方收取本轮所有分数牌，累计到对应阵营得分。

4.5 胜负结算

闲家总得分 = 桌面抓获分数 +（抠底成功则加底牌分数）

  • 庄家胜利：庄家得分 ≥ 本局叫分
  • 闲家胜利：闲家总得分 ＞（全局总分 - 叫分）

4.6 庄家轮转

  • 庄家本局获胜：下一局继续坐庄。
  • 庄家本局失败：庄家位置逆时针下移一位。

七、异常与离线处理

  1. 玩家离线/退出：自动托管出牌，优先跟花色、跟对子，不主动甩牌。
  2. 超时未操作：叫主/叫分阶段自动放弃；出牌阶段自动出最小合法牌。
  3. 房间人数不足：不可开始游戏，等待玩家加入。

九、核心测试用例

  1. 4人2副，叫分80，庄家刚好80分 → 庄家胜。
  2. 4人2副，叫分80，闲家得21分 → 闲家胜。
  3. 最后一轮闲家主牌获胜 → 抠底成功，底牌分计入闲家。
  4. 最后一轮闲家副牌获胜 → 不抠底，底牌分作废。
  5. 甩牌包含非最大牌 → 甩牌失败，强制出最小牌。
  6. 全员放弃叫分 → 流局，统计流动主数量判负。
  7. 切换3人/5人/6人模式 → 底牌、扣底数、总分、叫分区间自动适配。
  8. 关闭副牌甩牌开关 → 副牌甩牌提示不可用。
