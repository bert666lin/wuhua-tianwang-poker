## 项目定位
- 梅州五华地方扑克玩法电子化
- 方块3 = 天王（全场最大牌），1庄VS多闲同盟对抗
- 独立品牌「五华天王」，不挂荟影格局
- H5网页应用，点开即玩

## 技术栈
| 层 | 技术 | 用途 |
|---|---|---|
| 前端 | React + Vite (H5) | 牌桌UI、手牌、出牌动画 |
| 游戏服务器 | Colyseus (TypeScript) | 实时联机：房间管理、状态同步、断线重连 |
| API服务器 | FastAPI (Python) | 用户系统、排位积分、赛季数据 |
| 数据库 | PostgreSQL + Redis | 持久化数据 / 实时房间状态 |
| 牌面视觉 | CSS/SVG（先原型）-> 真实图片（后期） |

## 用户登录
- 游客模式（直接玩，不存数据）
- 微信OAuth网页授权（有服务号，用于排位/存档）

## 游戏内容（v1）
- 仅做4人标准场（2副牌，108张）
- 核心规则：叫主、叫分定庄、扣底、甩牌、跟牌、抠底、流局

## 对战模式
- 联机真人对战（核心体验，Colyseus）
- 单机AI对战（启发式AI，Phase 3）

## 社交功能
- 文字聊天 + 预设表情/快捷语（Phase 3）
- 语音消息条（Phase 3）

## 排位系统（Phase 2）
- 段位制（青铜->...->天王为最高段位）
- 赛季制（定期结算重置）

## 分阶段上线
| 阶段 | 内容 | 目标 |
|---|---|---|
| Phase 1 | 4人联机核心对局 + 游客登录 + 基础UI | 可玩、可分享 |
| Phase 2 | 排位段位 + 微信OAuth + 对局记录 | 可留存 |
| Phase 3 | 语音/文字聊天 + 单机AI + UI精修 | 成熟产品 |
